# 📖 Overview

The **Online Complaint Management System** is a Full Stack MERN application that allows users to register complaints digitally, monitor their complaint status, and communicate with administrators through an intuitive web interface.

The platform eliminates manual complaint handling by providing a secure, transparent, and efficient system for complaint submission, assignment, tracking, and resolution.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/anuradha449/your-platform-for-online-complaints.git
```

---

## Install Backend

```bash
cd server
npm install
```

---

## Install Frontend

```bash
cd client
npm install
```

---

## Configure Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```

---

## Run Backend

```bash
npm run server
```

---

## Run Frontend

```bash
npm start
```
